Zaahar Art & Interiors

A modern, elegant and responsive interior design website built for Zaahar Art & Interiors, showcasing thoughtful spaces, timeless aesthetics and functional design.

✨ Features
Responsive design for mobile, tablet and desktop
Modern and minimal user interface
Reusable React components
Smooth section navigation
Responsive hero section
Custom typography and color palette
Reusable buttons with primary and outline variants

🚀 Getting Started

Clone the repository:

bash
git clone https://github.com/jobanhanspal/zaahar-interiors.git


Navigate to the project:

bash
cd zaahar-interiors


Install dependencies:

bash
npm install


Start the development server:

bash
npm run dev
